Help Center

Everything you need to know about using ResumeIQ-X effectively.

🎓

Candidate Workflow

  1. Register your account with email verification
  2. Verify your email via OTP
  3. Login to your workspace
  4. Upload your resume file
  5. Wait for admin AI evaluation
  6. View your intelligence report in dashboard
👑

Admin Workflow

  1. Register admin account with OTP verification
  2. Login to admin portal
  3. View candidate queue in dashboard
  4. Trigger AI resume analysis
  5. Monitor real-time progress
  6. Results auto-released to candidates
🏢

Recruiter Workflow

  1. Open recruiter dashboard
  2. View candidate intelligence metrics
  3. Check domain distribution charts
  4. Evaluate role compatibility scores
  5. Inspect learning roadmap suggestions
📁

Supported Formats

  • PDF — Recommended format
  • DOCX — Microsoft Word
  • TXT — Plain text
  • PNG — Resume image
  • JPG / JPEG — Photo format
🔴

Status Meanings

Pending — Resume uploaded, awaiting admin review
Processing — AI engine running analysis
Completed — Report ready, dashboard unlocked
🔧

Troubleshooting

  • Ensure resume file is valid and not corrupted
  • Check your internet connection
  • Wait if admin evaluation is pending
  • Refresh dashboard if results not visible
  • Check spam folder for OTP emails
  • Use Gmail App Password for SMTP
