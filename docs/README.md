# ResumeIQ-X
### AI-Based Resume Analyzer and Job Recommendation Intelligence System

ResumeIQ-X is a semantic talent intelligence platform designed to analyze resumes using embedding-based reasoning instead of traditional keyword matching.

It evaluates candidate readiness, predicts career alignment, detects skill gaps, estimates confidence scores, and builds a persistent semantic talent memory layer.

This system is designed as a modular AI architecture capable of scaling into a recruiter intelligence platform and integrating with future research systems such as AFIS-X.

# Installation Guide

Clone repository:

git clone https://github.com/yourusername/ResumeIQ-X.git

Enter project folder:

cd ResumeIQ-X

Create Python environment:

Windows:

python -m venv venv  
venv\Scripts\activate

Linux / Mac:

python3 -m venv venv  
source venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Install FAISS:

pip install faiss-cpu

Install OCR engine:

Install Tesseract OCR

---

# Run Backend Server

Start Node API:

cd node_api  
node server.js

Start Python engine:

cd ai_engine_python  
python parser.py sample_resume.txt

---

# Launch Frontend

Open:

frontend/index.html

in browser
